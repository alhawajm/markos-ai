# MARKOS native launch assets

Uses the existing MARKOS WandSparkles mark and Sunlit rose color. Render with
`node scripts/generate-mobile-brand.mjs` from the repository root. Set
`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` if Chromium is installed outside Playwright.

PNG files are the build inputs; SVG files remain editable sources. The Android
foreground keeps the mark within the adaptive icon safe region. Screenshots for
store listings must come from the finished native app on actual supported sizes.

WandSparkles is from Lucide, used under the ISC license; see `LUCIDE-LICENSE`.
