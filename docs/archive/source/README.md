Historical numeric prices, vendor rates, model examples, delivery estimates, AWS assumptions, old visual tokens, Facebook-Page connection flow, old permission names, and provider limits were deliberately not promoted into current documentation. They are time-sensitive or superseded and must be researched again before use.

When an archived document conflicts with an active source, follow the active source. If it reveals a genuinely missing requirement, record the decision in `docs/decisions.md` and update the active source rather than reviving the archived file as authority.
