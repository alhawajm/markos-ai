# Archived UI Documentation

These files preserve dated design exports, implementation checklists, parity reviews, and state evidence. They are not current visual direction, mounted-route proof, or product requirements.

The active UI sources are:

- docs/ui-design-foundation.md — Sunlit visual and interaction foundation.
- docs/ui-ux-workflow.md — reference, prototype, implementation, and QA method.
- docs/ui-ux-improvement-plan.md — interpreted working backlog.
- docs/source/MARKOS_EXPERIENCE_FLOWS.md — behavioral authority.
- docs/source/MARKOS_BUILD_SPEC. 2.pdf — structural authority and target surface.

The pre-sunlit directory contains both earlier light/red material and the later dark AI Marketing Command Center pass. Useful obligations were retained in the active foundation and workflow: preserve real application behavior, implement honest states and next actions, validate responsive English and Arabic layouts, and avoid treating visual exports as production contracts.

When an archived file conflicts with an active source, follow the active source. If it reveals a missing requirement, interpret and record that requirement in an active document rather than reviving the archived checklist.
